## 建议你人工点验的最短路径

1. 清缓存 → 看引导页布局 → 进首页  
2. 空输入点「开始闯关」→ 应提示，按钮不置灰  
3. 「我的」改头像/昵称 → 回首页看头像与问候  
4. 完整走一局答题 → 看进度条、底栏固定、讲解无「正确答案：」前缀、加载页不闪回  
5. 通关报告：环进度、绿红对错、分享按钮、鼓励词换行  
6. 「我的」→ 闯关历史 → 直接进报告并可重闯
