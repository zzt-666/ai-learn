# Proposal

## Why

私有知识库 RAG 已可用，但对「习题 PDF / 正式题库」仍用固定线索 + Top-K 片段生成题目，导致来回刷到相近几题、大量原题覆盖不到，无法支撑期末全面刷题。需要把「刷题覆盖」与「学透要点」拆成两条产品路径，并先落地刷题闭环。

## What Changes

- 知识库增加**库级模式**：整库为 **刷题（drill）** 或 **学透（master）**，不可混用；创建/确认时后台可建议，用户确认后锁定。
- **刷题模式**：上传文档后规则优先拆题（低置信度可模型补拆），结构化题目写入 MySQL；仅保留单选/多选/判断文本题，图片题过滤；开局按用户选择题量从库中抽题（优先未刷），不走「每局 RAG Top-K 再生成整卷」。
- **已刷记录**存 MySQL；全部刷完后提示复习轮 / 重置进度 / 取消，禁止无提示假装还有新题。
- 原文无解析时，作答后可 **AI 懒生成解析并缓存**，角标区分来源。
- 新文档与当前库模式不符、或拆题失败/可用题为 0：提醒用户并阻断错误开刷，提供改学透/换文档；**不静默改库模式**。
- **学透模式**本变更保持现有 RAG 开局可用；章节地图/覆盖轮转等增强明确后置（P1），不在本变更实现范围内强交。
- 需求依据：`docs/知识库刷题优化需求分析文档.md` v0.2。

## Capabilities

### New Capabilities

- `knowledge-drill`: 库级刷题/学透模式、题库拆题入库与校验、抽题与已刷/复习轮、解析补全、模式不符提醒与阻断。

### Modified Capabilities

- `quiz-generation`: 从知识库开局时按库模式分流——刷题库组装已拆题目进入闯关；学透库继续材料优先 RAG 生成（本变更不改首页联网路由主契约）。

## Impact

- **后端**：`knowledge_bases` 增加模式字段；新增题目表与已刷记录表及 Alembic 迁移；拆题流水线（规则 + 可选模型补拆）；刷题开局 API/任务路径；解析懒生成接口或通关后异步补全。
- **前端**：库创建/详情展示与确认模式；刷题开局题量选择；刷完复习轮弹层；解析来源角标；不符模式提示。
- **不动**：EXP/历史公式、OSS 迁移、错题本完整产品、学透章节地图（P1）、Rerank 专项。
- **外部**：拆题补拆与解析生成会额外消耗 DeepSeek（或既有）模型额度；刷题发题主路径不依赖 Embedding/Chroma。
